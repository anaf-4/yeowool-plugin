# 카지노 라운지 설계

## 목표
설치된 카지노 장식 가구(`iavegastables:<이름>_decor`, ItemsAdder 가구)를 우클릭하면 미니게임이 열린다. 게임은 **칩**으로만 하고, 칩은 **온으로 사고 온으로만 되판다** (캐시로는 절대 못 산다).

## 모듈·저장
- `yeowool-market` (경제 모듈), 새 패키지 `casino`.
- 칩은 **DB 잔액**(아이템 아님 → 복사 불가): `yw_casino_chips(uuid PK, chips BIGINT)`. 모든 변경은 조건부 UPDATE 한 문장 (`chips = chips - ? WHERE chips >= ?`), JDBC는 작업 스레드.
- 기록: `yw_casino_log(id, uuid, game, bet, payout, detail, created_at)`, 일일 구매량 `yw_casino_daily(uuid, day, bought, PRIMARY KEY(uuid, day))`.

## 칩 환전
- **1칩 = 1,000온** (설정 `casino.chip-price`).
- **구매**: 온 차감(메인 스레드 `modifyBalance`) → 칩 증가(작업 스레드). 칩 증가가 실패하면 온 환불.
- **판매(칩 → 온)**: 칩 조건부 차감(작업 스레드) 성공 시 → 메인 스레드에서 온 지급 (플레이어가 나갔으면 `core.payouts().enqueue`).
- **하루 구매 한도 500칩** (설정 `casino.daily-buy-limit`, 서버 시간 자정 기준, 세 서버 합산). 판매는 한도 없음.
- 환전 창구: `/카지노` 명령 (칩 잔액·구매·판매 GUI, 수량 선택 1/10/100/직접입력) — 어디서나 가능. (설정 `casino.exchange-anywhere: true`, false면 환전 NPC(Citizens, `/카지노관리 npc`)에서만)

## 게임 (가구 → 게임 연결, 설정으로 변경 가능)
| 가구 | 게임 | 규칙 (기본값) |
|---|---|---|
| `classic_decor` (슬롯머신) | **슬롯머신** | 3릴, 그림 7종 가중치 뽑기. 3개 같으면 그림별 배당(예: 체리 ×5 … 7 ×50), 체리 2개 ×2. 목표 환수율 약 95% (그림 가중치·배당은 설정) |
| `roulette_decor` | **룰렛** | 유럽식 0~36. 베팅: 숫자(×36), 빨강/검정·홀/짝·1~18/19~36(×2), 1/2/3구간(×3). 0에 걸리면 외부 베팅은 짐 (환수율 97.3%) |
| `dice_decor` | **주사위 하이/로우** | 주사위 2개 합(2~12). 하이(8~12)/로우(2~6) ×2, 7 ×4. 7이 나오면 하이·로우 모두 짐 |
| `blackjack_decor` | **블랙잭** | 딜러 1:1, 딜러 17에서 스탠드, 블랙잭 ×2.5, 승리 ×2, 무승부 환급, 히트/스탠드/더블다운. 한 판이 끝날 때까지 칩은 묶여 있음 |
- 나머지 장식 가구는 장식 그대로 (우클릭해도 아무 일 없음).
- 게임 창: 베팅 금액 버튼(1·5·10·50·100칩, 최대 `casino.max-bet` 기본 100칩), 결과 연출(슬롯 회전·룰렛 칸 이동 애니메이션 몇 틱), 결과 메시지.
- **처리 순서**: 베팅 칩을 먼저 조건부 차감(작업 스레드) → 성공 시 결과를 서버에서 뽑음(`SecureRandom`) → 당첨금 칩 지급 → 기록. 클릭 연타 방지(처리 중 잠금), 창을 닫거나 나가도 이미 차감된 판은 끝까지 정산(블랙잭은 나가면 스탠드로 처리).
- **큰 당첨 공지**: 배당 ×20 이상 또는 당첨 칩 ≥ 1,000이면 세 서버 공지(DB 공지 테이블 폴링, 기존 주문 엔진 방식).

## 관리
- `/카지노관리` (권한 `yeowool.market.casino.manage`, op): `칩 <닉네임> [지급|회수|확인] [수량]`, `기록 <닉네임>`(최근 20판), `npc`(환전 NPC 연결·해제), `리로드`.
- 설정 `casino:` 블록: chip-price, daily-buy-limit, max-bet, exchange-anywhere, 게임별 사용 여부·가구 id·배당표.
- 로그: 칩 구매·판매는 core LogService("casino")로 남김.

## 예외·안전
- ItemsAdder가 없으면 게임 연결 끔(환전은 동작).
- 서버 종료 중 결과 정산이 메인 스레드로 못 넘어오면 로그로 남김(칩은 DB에서 이미 정산됨 — 칩은 작업 스레드에서 한 트랜잭션으로 차감·지급하는 편이 안전: 베팅 차감과 당첨 지급을 **한 트랜잭션**에서 처리하고, 메인 스레드는 표시만).

## 테스트
JUnit: 슬롯 배당 계산·환수율(시뮬레이션 10만 판이 설정 목표 ±2% 안), 룰렛 베팅 판정, 주사위 판정, 블랙잭 점수(에이스 1/11)·딜러 규칙, 일일 한도 계산.
