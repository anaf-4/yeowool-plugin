# 강화 초월 시스템 설계

## 목표

30강 이후에도 성장할 목표를 만든다. 30강 → 1차 초월(네더라이트로 변경, 0강부터) → 10강에서 2차 초월 → 20강에서 3차 초월 → 30강이 최고 성능.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 강화 수치 | 1차 초월 후 0강부터, 2·3차 초월은 수치 유지 |
| 구간 상한 | 초월 전 30(max-level), 1차 10, 2차 20, 3차 30 — 상한에 닿으면 다음 초월 전까지 강화 불가 |
| 네더라이트 변환 | 1차 초월 성공 시 나무/돌/철/금/다이아/가죽/사슬 → 네더라이트(검·도끼·곡괭이·삽·괭이·투구·흉갑·각반·신발). 변환 없는 장비(활·석궁·삼지창·겉날개·거북 투구)는 재질 유지, 초월은 가능 |
| 초월석 | 단계별 3종 — 1차(파랑), 2차(보라), 3차(빨강). GemsAndStones 10번 모양. ItemsAdder `yeowool_enhance:transcend_stone_1/2/3` (PAPER, model_id 140110~140112) |
| 초월 비용·확률 | 1차: 1차 초월석 1 + 50만 온, 60% / 2차: 2차 초월석 1 + 100만, 40% / 3차: 3차 초월석 1 + 200만, 25% (설정) |
| 초월 실패 | 초월석·온만 소모, 장비는 그대로 |
| 능력치 | 초월 전 `강화 × 1당 보너스 × 등급 배율`(기존). 초월 후 `(30 + 강화) × 1당 보너스 × 초월 배율`, 배율 1차 3.2 / 2차 3.6 / 3차 4.2 (신화 3.0보다 커서 초월 직후 하락 없음) |
| 초월 후 강화 | 비용(온)은 기존 단계별 비용 × 초월 단계 배율(1차 2, 2차 3, 3차 4). 초월한 장비는 강화 실패로 파괴되지 않음(파괴 → 하락으로 대체, 설정 가능) |
| 도구 | 곡괭이·삽·괭이 강화·초월 가능(도끼는 이미 무기). 능력치 = 채굴 속도(`MINING_EFFICIENCY`) `1당 0.3` |
| 표시 | 이름 "+12강 [2차 초월] …", 등급 = 초월 단계 이름·색, 툴팁 테두리 최고 등급 |
| 초월석 획득 | 월드보스(1위 3차 1개, 2위 2차 1개, 3위 1차 2개, 참여자 20% 확률 1차 1개 — 설정의 콘솔 명령어), 보물지도·레이드 보상(관리진이 기존 보상 GUI에 넣음), 관리진 `/초월석 지급` |

## 기존 버그 수정 (같이 처리)

1.21부터 아이템에 능력치 수정값이 하나라도 있으면 재질 기본 능력치(검 기본 공격력 등)가 적용되지 않는다. 현재 강화는 강화 보너스만 넣어서 **강화한 무기·방어구의 기본 공격력/방어력/공격 속도가 사라진다**. 재구성 시 재질 기본 수정값(`Material#getDefaultAttributeModifiers()`)을 먼저 넣고, 다른 플러그인이 넣은(비-minecraft 네임스페이스) 수정값은 보존한 뒤 강화 보너스를 더한다. 네더라이트 변환 후에도 네더라이트 기본값이 적용된다.

## 데이터

아이템 PDC에 `enhance_transcend`(0~3) 추가. 기존 장비는 0(초월 전)으로 그대로.

## 명령어

- `/강화`: 상한(초월 지점)이면 강화 버튼이 "초월하기"로 바뀜.
- `/초월석 지급 <닉네임> <1|2|3> [개수]` (op): 오프라인·다른 서버여도 우편함으로. 콘솔 실행 가능(월드보스 보상용).

## 월드보스 연동 (`yeowool-raid`)

`world-boss.rank-commands.<순위>`, `participation-commands`, `participation-command-chance`(%) — 처치 시 콘솔로 실행, `{player}` 치환. 기본값은 위 초월석 지급.

## 테스트

JUnit: `TranscendRules`(구간 상한, 초월 가능 판정, 네더라이트 변환 이름, 능력치 공식·초월 직후 하락 없음), `EnhanceConfig`(초월 단계 파싱). 인게임: 30강 → 1차 초월(네더라이트·0강) → 10강 초월 버튼 → 2차 → 20강 → 3차 → 30강, 실패 시 장비 유지, 기본 능력치 유지, 곡괭이 채굴 속도, 월드보스 처치 시 초월석 우편.
